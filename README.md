# nixos-config

[![Nix checks](https://github.com/sshawn9/nixos-config/actions/workflows/checks.yml/badge.svg?branch=main)](https://github.com/sshawn9/nixos-config/actions/workflows/checks.yml)

The workflow builds every target exposed through `checks` on native Linux and Darwin runners for x86_64 and aarch64. Open the workflow run for the platform matrix, per-target results, and build durations. Platforms without targets produce an empty successful test suite.
